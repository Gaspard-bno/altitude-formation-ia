# 🧠 Kit second cerveau — Altitude by DreamFly

Un point de départ **vierge** pour votre second cerveau sur Obsidian. Aucune donnée personnelle.

## Démarrer en 3 minutes
1. Installez **Obsidian** (gratuit) : obsidian.md
2. « Open folder as vault » → choisissez CE dossier.
3. Vous avez déjà la structure **PARA** + une **Inbox**.

## La structure
- **00 Inbox/** — on jette TOUT ici d'abord (capture rapide). On range ensuite.
- **01 Projects/** — ce qui a une échéance / un objectif précis.
- **02 Areas/** — vos responsabilités continues (santé, finances, métier…).
- **03 Resources/** — sujets d'intérêt, documentation, références.
- **04 Archives/** — ce qui est terminé ou en pause.
- **Templates/** — modèles (note atomique, note du jour).
- **Exemples/** — un exemple pour comprendre.

## La règle
**Capturer d'abord, organiser ensuite.** Une idée = une note. Le titre est une affirmation, pas « Note 1 ».
