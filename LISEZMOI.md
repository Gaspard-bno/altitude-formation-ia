# Altitude — Maîtriser l'IA (by DreamFly)

Formation IA de A à Z, **bilingue FR / PT-BR**. Site autonome, rien à installer.

## Ouvrir
Double-cliquez sur **`index.html`** → s'ouvre dans votre navigateur (Chrome, Edge, Firefox, Safari). Marche sur Mac et Windows.

## Utiliser
- Barre latérale : 12 modules. Badges 🟢 débutant · 🟡 intermédiaire · 🔴 avancé.
- Bouton **FR / PT** en haut à droite : bascule toute la formation.
- Bouton **Copier** sous chaque prompt.
- Votre progression (modules terminés) est mémorisée dans le navigateur.

## Héberger (optionnel)
Déposez le dossier `site/` sur n'importe quel hébergement statique (Netlify, GitHub Pages, Vercel…) ou servez-le localement. Aucun serveur applicatif requis.

## Dans le dossier
- `index.html` + `assets/` + `content/` : la formation.
- `kit-obsidian/` : votre second cerveau vierge (module 6). Ouvrez-le comme coffre dans Obsidian.
- Livrets PDF (FR + PT) : fournis à côté, pour impression.
